# fastLink

Fast Probabilistic Record Linkage with Missing Data. Implements the Fellegi-Sunter probabilistic record linkage model with an EM algorithm, as described in Enamorado, Fifield, and Imai (2019, *American Political Science Review*).

## Project structure

- `R/` — R source files (main package code)
- `src/` — C++ source (Rcpp/RcppArmadillo/RcppEigen, OpenMP-parallelized)
- `man/` — Generated roxygen2 documentation (do not edit by hand)
- `tests/testthat/` — testthat unit tests
- `data/` — Included datasets (.RData)
- `DESCRIPTION` — Package metadata and dependencies
- `NAMESPACE` — Exports/imports (generated by roxygen2, do not edit by hand)

## Key source files

| File | Purpose |
|------|---------|
| `R/fastLink.R` | Main wrapper function orchestrating the full linkage pipeline |
| `R/emlinkMARmov.R` | EM algorithm for Fellegi-Sunter model under MAR assumption |
| `R/emlinklog.R` | EM with log probabilities for numerical stability |
| `R/gammaCKpar.R` | String agreement patterns (Jaro-Winkler) |
| `R/gammaKpar.R` | Numeric agreement patterns |
| `R/blockData.R` | Blocking to reduce comparison space |
| `R/dedupeMatches.R` | Deduplicate to ensure 1-to-1 matches |
| `R/getMatches.R` | Extract matched records from output |
| `src/m_func_cpp.cpp` | Core C++ computation (pairwise distances, parallel matching) |

## Development setup

**macOS with Homebrew (required for OpenMP support):**

```bash
brew install gcc
```

Ensure `~/.R/Makevars` points to Homebrew's gcc/g++ rather than Apple clang so OpenMP works. Example:

```
CC = /opt/homebrew/bin/gcc-14
CXX = /opt/homebrew/bin/g++-14
```

**R dependencies:**

```r
install.packages(c("devtools", "roxygen2", "testthat", "Rcpp",
                   "RcppArmadillo", "RcppEigen", "stringdist",
                   "data.table", "dplyr", "foreach", "doParallel",
                   "adagio", "plotrix"))
```

## Build and check

The legacy `builder.sh` script documents the full build cycle. The equivalent commands:

```bash
# 1. Generate native routine registration, docs, and Rcpp exports
R -e 'sink("src/fastLink_init.c"); tools::package_native_routine_registration_skeleton(".", character_only = FALSE); sink()'
R -e 'devtools::document()'
R -e 'Rcpp::compileAttributes(verbose = TRUE)'

# 2. Clean compiled objects
rm -f src/*.o src/*.so src/*.rds

# 3. Build, check (CRAN-style), and install
cd .. && R CMD BUILD fastLink --resave-data
R CMD CHECK fastLink_*.tar.gz --as-cran
R CMD INSTALL fastLink_*.tar.gz
```

**Quick iteration (tests only):**

```r
devtools::test()
```

**Full check:**

```r
devtools::check()
```

## Sensitive areas — edit with care

- **C++/Rcpp code (`src/`)**: Uses OpenMP parallelization, Armadillo matrices, and Eigen sparse matrices. Changes here can cause segfaults or silent numerical errors. Always rebuild and run full checks after modifying.
- **EM algorithm (`R/emlinkMARmov.R`, `R/emlinklog.R`)**: Numerically sensitive. Small changes to convergence criteria, initialization, or probability calculations can break linkage accuracy. Validate against known test cases.
- **`src/fastLink_init.c`**: Auto-generated — regenerate with `tools::package_native_routine_registration_skeleton()`, never edit by hand.

## Code style

No strict style guide enforced. Match existing patterns in the file you're editing:

- Function names are generally camelCase (e.g., `gammaCKpar`, `fastLink`, `dedupeMatches`)
- Documentation uses roxygen2 (`@param`, `@return`, `@export`, `@examples`)
- `man/` files and `NAMESPACE` are generated — edit roxygen comments in `R/` files, then run `devtools::document()`

## Testing

Tests live in `tests/testthat/test_wrapper.R`. Run with:

```r
devtools::test()
```

Tests cover the main `fastLink()` wrapper, input validation, and results correctness on sample data (`dfA`, `dfB`).

## Package data

- `dfA`, `dfB` — Sample datasets for examples/tests (500 and 350 records)
- `countyoutflow`, `countyinflow`, `irs_statemigration` — IRS migration data used by `calcMoversPriors()` for geographic prior probabilities
